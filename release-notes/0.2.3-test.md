# AlphaWRT 0.2.3-test

- **Channel:** Test pre-release
- **Target:** Skyworth GN630V (Airoha EN7523)
- **Build:** OpenWrt r37113+163, revision `e4974473db`
- **Verification level:** Owner-reported on-device testing; full HIL matrix not documented

> **Do not flash on the 2.5G GN630V.** Only the AX3000 GN630V variant is supported by this test build; the 2.5G variant is untested and may be incompatible. Check the full model/variant marking on the device label.

This test build includes the GN630V LED mapping update, IPv6 client/server packages, fibre diagnostics, and the current Quick Setup cleanup. The project owner confirms that this firmware was tested on the GN630V and that IPv6 is working. The release record does not yet contain evidence for every HIL acceptance category.

## Downloads

- `*-squashfs-tclinux-factory.bin` — install through the stock firmware web UI.
- `*-squashfs-sysupgrade.bin` — upgrade a running AlphaWRT installation.
- Use the factory image only from stock; use sysupgrade only from AlphaWRT. Do not sysupgrade stock firmware.
- `SHA256SUMS` — SHA-256 checksums for both images.
- `ONT-ISP-TESTER-GUIDE.md` — safe, redacted test procedure and report template.
- `*.manifest` — package manifest for this build.

Check the downloaded file against `SHA256SUMS` before flashing. Keep the stock firmware in the other bank and read the [recovery guide](https://github.com/idiazraz/gn630v-alphawrt/blob/v0.2.3-test/docs/RECOVERY.md) before testing. The [tester guide](https://github.com/idiazraz/gn630v-alphawrt/blob/v0.2.3-test/docs/ONT-ISP-TESTER-GUIDE.md) is also attached to this release.

## Changes

- Corrected GN630V LED pin mapping and LAN link/activity triggers.
- Included IPv6 support: DHCPv6 client, IPv6 router advertisements/DHCP service, and LuCI IPv6 protocol support.
- Added fibre link-quality counters and the fibre diagnostics view.
- Removed unverified ISP VLAN and ONT identity presets. TIME preselects PPPoE and Allo preselects DHCP; VLAN and OMCI values require line-specific verification.
- Added a tester guide that avoids collecting serials, credentials, MAC addresses, flash dumps, or packet captures.

## Known issues and test limits

- This is a test release for one target model. The project owner reports testing this image on the GN630V; the full evidence matrix for startup, core features, abnormal/recovery paths, sustained operation, and upgrade/rollback has not been recorded, so the release is not marked **HIL Verified**.
- IPv6 is confirmed working by the project owner on the tested firmware.
- The LED mapping update is included. Detailed panel-by-panel LED test results are not recorded here; Wi-Fi/WPS indication may remain incomplete.
- Live GPON service and upstream Internet traffic remain under test. Keep the stock ONT available for recovery.
- Reproducible-build status has not been established for this artifact.
