# AlphaWRT 0.2.3-test

- **Channel:** Test pre-release
- **Target:** Skyworth GN630V AX3000 (Airoha EN7523 / AN7529CT)
- **Build:** OpenWrt r37113+163, revision `e4974473db`, built from `config/gn630v.config` at this tag
- **Tested:** on one GN630V on a live TIME fibre line (Huawei OLT), in combo and bridge mode. Not yet HIL verified: see "Known issues".

> **Do not flash the 2.5G GN630V.** This build supports only the AX3000 GN630V. The 2.5G variant is untested and may be incompatible. Check the full model marking on the label.

**Fibre internet works.** AlphaWRT registers on the ISP's fibre and carries your internet, either by dialing PPPoE itself (combo mode) or by passing the line to your own router (bridge mode). On the test line:
- Registration took about 50 s from power-on.
- Combo mode reached about **900 Mbps download / 550 Mbps upload over IPv4**, carried by the hardware packet engine.
- IPv6 worked at about 480 Mbps download, through the CPU.

## Downloads
- `*-tclinux-factory.bin`: first install, from the stock firmware web UI. Keep `tclinux` in the file name.
- `*-sysupgrade.bin`: upgrade a running AlphaWRT. Never sysupgrade the stock firmware.
- `SHA256SUMS` and `*.sha256`: check the file before flashing.
- `ONT-ISP-TESTER-GUIDE.md`: how to test on your line and report safely (no serials, passwords or MACs).
- `*.manifest`: the package list of this build.

The stock firmware stays in the other flash bank, so you can always switch back. Read the [recovery guide](https://github.com/idiazraz/gn630v-alphawrt/blob/v0.2.3-test/docs/RECOVERY.md) before flashing.

## What's new since 0.2.0-test
- **Fibre:**
  - Live GPON registration and internet.
  - Fixed an upstream stall that stopped all traffic after a few hundred packets.
  - The internet VLAN is taken from what the ISP's OLT provisions.
- **Quick Setup**, one step per page:
  - admin password, Basic or Advanced interface, your ISP;
  - **Combo**, **Bridge** or **Router** mode;
  - settings with a short guide under each box;
  - a fibre step that saves the identity first, then shows the box registering.
- **ISP presets, only from the project's own sources:**
  - **Unifi (TM):** from the GN630V's own stock firmware, which TM supplies. Internet is PPPoE on VLAN 500 (IPTV 600, voice 400 and TR-069 209 are noted). A TM-supplied, provisioned GN630V can copy its saved identity with **Use the identity saved by the stock firmware**.
  - **TIME:** from the live test line. PPPoE on VLAN 499, OMCC 128, and a **Huawei HG8145X6** ONT profile that registered with these values.
  - **Allo and other ISPs:** manual. No third-party presets are bundled.
- **Fibre diagnostics** (Basic → Fibre):
  - a plain-language verdict, e.g. "light too weak" or "line errors with good light: ISP side";
  - received light with its 24 h range;
  - line-error counters: HEC (the stock "HEC errors"), BIP, CRC, LOF and FEC;
  - an event log, including the ISP server's own login messages ("You are already logged in");
  - a downloadable report for ISP tickets, with secrets left out.
- **Speed:** hardware offload for IPv4 TCP, software flow offload for the rest, and both CPU cores in use.
- **LEDs and buttons:**
  - PON on while the fibre has light, and LOS blinking when it doesn't.
  - Internet on when connected, blinking with traffic.
  - LAN link and activity; USB, VoIP, TEL and WPS LEDs mapped.
  - Reset button: a short press reboots, and holding it 5 s or more resets to defaults. WPS button mapped.
- **Also new:**
  - IPv6: DHCPv6 client, router advertisements and the LuCI IPv6 protocol.
  - The stock web login is hidden from the kernel command line.
  - Firmware banks in Basic → System.
  - Both Wi-Fi radios are enabled by Quick Setup.

## Known issues and test limits
- **One line tested:** only TIME has been tested live. The Unifi preset comes from the stock firmware but hasn't been tested on a TM line yet. Testers on other ISPs are welcome: see the tester guide.
- **Moving the line from another router:** TIME allows one PPPoE session per account. Until the old session expires (a few minutes), the login is refused; Home shows the ISP's message, and the box keeps retrying.
- **IPv6 and UDP use the CPU:** hardware offload for IPv6 is in the image but off until it's verified.
- **Wi-Fi LED:** not working yet.
- **Untested here:** holding the reset button for a factory reset.
- **Not HIL verified:** sustained operation, failure and recovery paths, and upgrade/rollback have not been recorded as a full test matrix.
- **Reproducibility:** whether the build is reproducible has not been checked.
