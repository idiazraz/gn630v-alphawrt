# AlphaWRT 0.4.2-test

- **Channel:** Test (tester build, not a release)
- **Target:** Skyworth GN630V AX3000 (Airoha EN7523 / AN7529CT)
- **Build:** OpenWrt r37113+195-e4974473db, built by `build.sh` from `config/gn630v.config` and `config/feeds.conf`, on a local machine (clean build)
- **Acceptance:** not run on hardware yet; built for one TM Unifi tester

> **Do not flash the 2.5G GN630V.** This build supports only the AX3000 GN630V.

0.4.1 plus one fix for TM Unifi lines where the fibre registers but the internet never comes up.

## Downloads
- `*-sysupgrade.bin`: upgrade a running AlphaWRT. Settings are kept.
- `*-tclinux-factory.bin`: first install, from the stock firmware web UI. Keep `tclinux` in the file name.
- `SHA256SUMS`: check the file before flashing.

## What's new since 0.4.1
### Fixed
- **Unifi (TM) fibre: no internet, the line registers but never gets service.** The box now tells the provider's equipment about every kind of setting the stock firmware supports, so TM's Nokia equipment no longer stops before setting up the internet connection. Not yet confirmed on a Unifi line.

## For the tester
After the upgrade, set the OLT profile back to auto, then reboot:

```
uci set omci.main.olt_profile='auto'; uci commit omci; reboot
```

If the internet still doesn't come up, send the output of:

```
ubus call omci.agent status; ubus call omci.agent mib_list | grep -c '"olt"'; logread | grep -iE 'omci|pppd' | tail -50
```
