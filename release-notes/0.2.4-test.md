# AlphaWRT 0.2.4-test

- **Channel:** Release (test build)
- **Target:** Skyworth GN630V AX3000 (Airoha EN7523 / AN7529CT)
- **Build:** OpenWrt r37113+164, revision `e4974473db`, built on the local machine from the same sources as `build.sh` at this tag (a `build.sh` build names itself r37113+170: the patches are one commit each there)
- **Acceptance:** Partly HIL verified, see "Hardware acceptance"

> **Do not flash the 2.5G GN630V.** This build supports only the AX3000 GN630V. The 2.5G variant is untested and may be incompatible. Check the full model marking on the label.

This release makes the fibre side follow the ISP's OLT more closely: it applies the OLT's VLAN tagging rules and gives each VLAN its own GEM port. It also adds WireGuard VPN, a clearer Home page and a Unifi IPTV option. It is a test build: kernel dynamic debug is on, so testers can capture the OMCI details an ISP problem needs.

## Downloads
- `*-tclinux-factory.bin`: first install, from the stock firmware web UI. Keep `tclinux` in the file name.
- `*-sysupgrade.bin`: upgrade a running AlphaWRT. Never sysupgrade the stock firmware.
- `SHA256SUMS` and `*.sha256`: check the file before flashing.
- `ONT-ISP-TESTER-GUIDE.md`: how to test on your line and report safely (no serials, passwords or MACs).
- `*.manifest`: the package list of this build.

The stock firmware stays in the other flash bank, so you can always switch back. Read the [recovery guide](https://github.com/idiazraz/gn630v-alphawrt/blob/v0.2.4-test/docs/RECOVERY.md) before flashing.

## What's new since 0.2.3-test
- **Fixed:** fresh installs from the stock web UI no longer leave the LAN unreachable ([#1](https://github.com/idiazraz/gn630v-alphawrt/issues/1)). With the fibre WAN as set up on first boot, the hardware offload rule stopped the whole firewall from loading. It now has its own table.
- **Fibre:**
  - The OLT's VLAN tagging rules (OMCI ME 78) are applied: frames the ISP expects tagged on a LAN port get the ISP's VLAN on the way up, and it is removed on the way down.
  - Each VLAN the OLT provisions gets its own GEM port, and the OLT's VLAN filters apply only to the WAN port.
  - When the OLT resets the box's fibre settings (an OMCI MIB reset), it shows in the Fibre page event log.
- **WireGuard VPN:** WireGuard with QR codes for phone peers, a "VPN" entry in the Basic menu, and policy routing (pbr). The tunnel MTU defaults to 1412, which fits inside PPPoE.
- **Home page:** the Internet card shows the gateway and DNS ("Encrypted via …" when DNS goes through dnsproxy). A new "This box" card shows the firmware and the LAN address, and in bridge mode the management address and the port to reach it from.
- **Unifi IPTV:** Quick Setup can put Unifi IPTV (VLAN 600) on LAN 4 in combo mode, for the set-top box. Untested on a Unifi line: testers wanted, see the tester guide.
- **LEDs:** the Wi-Fi LED follows the radios, and the power LED stays on after boot (it went dark once the boot blinking ended).
- **Speed and stability:** larger receive rings, including the one that carries PPPoE logins, and interrupt coalescing settings (off by default) for tuning.
- **Build:** `build.sh` pins the feeds and the commit dates, and a CI workflow builds the images on Linux.

## Reproducibility
- **The build is reproducible:** two CI builds of the same commit, with one signing key, gave identical `SHA256SUMS` ([run 40283773281](https://github.com/idiazraz/gn630v-alphawrt/actions/runs/40283773281), on the 0.2.3-test sources).
- **These images were not rebuilt twice:** they are a local build. A CI or local build of this tag uses a different package-signing key (`/etc/apk/keys/public-key.pem`) and names itself r37113+170, so its checksums differ from the files here.

## Known issues and test limits
- **One line tested:** only TIME has been tested live. The Unifi preset and the Unifi IPTV option haven't been tested on a TM line yet.
- **Mostly tested in bridge mode:** combo mode was checked after a fresh install (PPPoE up), not soaked. IPv6/UDP hardware offload and the combo upload ceiling are for 0.2.5.
- **IPv6 and UDP use the CPU:** hardware offload for IPv6 is in the image but off until it's verified.
- **Moving the line from another router:** TIME allows one PPPoE session per account. Until the old session expires (a few minutes), the login is refused; Home shows the ISP's message, and the box keeps retrying.
- **Untested here:** holding the reset button for a factory reset.
- **Quick Setup, ISP fibre box model:** after choosing a model, the "Model details" fields still look empty. The values are set and applied; go Back, then Next to see them. Fixed for the next build.
- **WireGuard QR code in bridge mode:** LuCI's "Generate configuration" shows no QR code when the box has no Internet address of its own (upstream LuCI). It works in combo or router mode.
- **Acceptance rows not run:** A1–A4, A6–A9, A11.
